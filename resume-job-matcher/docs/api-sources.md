# External Job API Sources

## Himalayas
Candidate source adapter: the public jobs API. Confirm current API terms,
allowed use, attribution, rate limits, and data-retention requirements before
enabling scheduled ingestion.

## MeroJob
Do not crawl or ingest without explicit permission and a supported integration.
The adapter is a placeholder only.

## Manual seed data
Local fixture data may be used for development and tests. Do not treat sample
records as live vacancies.
