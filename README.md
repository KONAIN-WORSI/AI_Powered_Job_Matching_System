#AI Powered Job Matching System

This project is a web-based Recruitment Intelligence and Skill Matching Platform designed to help candidates discover relevant jobs and help recruiters search and review candidates. The system accepts a candidate resume, extracts structured information and skills using NLP, retrieves job postings from permitted external sources, parses job requirements, generates semantic representations, and compares candidate profiles with jobs using vector similarity and structured skill information. The platform also provides recruiter dashboards, job recommendations, market analytics, and asynchronous processing.

The project is intentionally designed as decision-support software rather than an automated hiring decision system. It explains why a job is relevant by showing matched skills and other extracted information instead of claiming that a candidate is objectively suitable for employment.
